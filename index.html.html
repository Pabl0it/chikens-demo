5 Formas de Incrustar Power BI en tu GitHub Page

Dado que soy una IA y no puedo enviarte archivos JPG/PNG directamente por el chat, he programado este archivo web con 5 "maquetas" (mockups) visuales exactas de cómo luce un iframe de Power BI en distintos diseños de páginas web.

1. Estilo "Dashboard a Pantalla Completa"

El iframe ocupa el 100% del ancho. Ideal para cuando la página de GitHub es exclusivamente para mostrar el reporte.

📊 XenoFuel General Overview - Microsoft Power BI
Total Revenue⌬ 1.2T
Extraction14.8 kT
ROI+315%

2. Estilo "Artículo Narrativo"

En este diseño, incrustas el <iframe> de Power BI en medio del texto de tu GitHub Page. Es excelente para el "Data Storytelling". El lector va leyendo el contexto de tu negocio, y luego interactúa con el gráfico a la derecha para comprobar tus puntos.

El reporte se ajusta a una caja más pequeña (por ejemplo 400x300 píxeles), mostrando una sola página del informe diseñada específicamente para ese espacio.

📊 Market Share Analysis

3. Adaptación a Temas Oscuros (Dark Mode)

Si tu página tiene un diseño alienígena como el USS Leviathan, puedes diseñar tu Power BI en Power BI Desktop con un tema oscuro (fondo negro, letras verdes) para que al incrustarlo con el iframe, parezca una parte nativa de la web y no un parche blanco.

[>] USS LEVIATHAN - TELEMETRY.pbix
84,092 Drones Activos

4. Estilo "Widgets de Gráficos"

En lugar de un solo iframe gigante con todo el reporte, Power BI te permite incrustar *gráficos individuales*. Aquí puedes usar CSS Grid en tu GitHub Page para colocar 3 iframes separados, creando un diseño muy limpio.

Sales by Region
Monthly Growth
Target Goal

5. Estilo "Panel Lateral de Navegación" (Sidebar)

La página de GitHub maneja la estructura (menú a la izquierda) y el iframe de Power BI se despliega en el contenedor principal derecho. Las pestañas de Power BI se ocultan en la configuración del iframe para que parezca una aplicación nativa.
